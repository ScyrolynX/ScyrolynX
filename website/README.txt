SCYROLYNX WEBSITE — V3

Files
- index.html: site content and structure
- styles.css: visual design, responsive behavior, and animations
- script.js: mobile navigation, header behavior, and scroll reveals

Local preview
1. Keep all three files in the same website directory.
2. Open index.html in a browser, or use a local static server.
3. Test the navigation at desktop and mobile widths.
4. Test the project enquiry link. It opens the visitor's default email application; it does not submit to a server.

Deployment
Copy these files into the repository's website/ directory, inspect with git diff, then commit and push. A push deploys only if Cloudflare Pages is configured to build from that branch and directory.

Truthfulness note
The invoice section is labeled as a demonstration using sample data, not a deployed client project. Update it as features are actually implemented and tested.
