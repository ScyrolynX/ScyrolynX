05 / GOOD QUESTIONS

Before we
get into it.

A few practical notes on what working together can look like.

Ask something else ↗
What kinds of problems can ScyrolynX help with?

Repetitive manual tasks, disconnected tools, data-processing workflows, internal software needs, and focused backend or API work. The first step is understanding the problem before choosing the technology.

Do I need a fully defined technical specification?

No. A clear description of the process, what is frustrating about it, and what a better outcome would look like is a useful starting point. We can work out the technical shape from there.

Can you work with an existing system?

Potentially, yes. Existing tools, data formats, APIs, and constraints are part of the discovery process. The right approach depends on access, complexity, and the outcome you need.

Do you work with clients outside Africa?

ScyrolynX is based in Africa and is open to working with clients across borders. Project fit, communication, scope, and timelines are discussed up front.

What should I include in my first message?

Tell us what you are trying to do, how the process works today, what is going wrong or taking too long, and any deadline or existing tools we should know about. You do not need to have the solution figured out.
